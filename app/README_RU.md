# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

Инженерное приложение для расчёта стартового EBAM G-code под установку Бормаш/LinuxCNC.

## Назначение

Приложение помогает подготовить расчётный G-code для электронно-лучевой проволочной наплавки:

- STL / DXF / CSV / стандартные фигуры → G-code;
- режим чаш, горшков, стаканов, конусов и шар-баллонов;
- **новый режим поворотного стола C для чаш/баллонов**;
- специальные траектории чаш/баллонов: C-кольца, XY-кольца, XY-спираль, старое заполнение;
- расчёт E0/E1/E2/F, слоёв, времени, проволоки и энергии;
- 3D-предпросмотр чаш/баллонов и предпросмотр проходов;
- аудит G-code перед запуском;
- обратный анализ готового G-code;
- профиль Бормаш с проверкой лимитов X/Y/Z;
- всплывающие подсказки `?` для изменяемых параметров.

## Что нового в v4.2.9.6

Добавлена стратегия `Поворотный стол C — кольца B=0` для режима `Чаши/баллоны`.

Суть режима:

- B фиксирован, по умолчанию `B=0`;
- X задаёт радиус: `X = X_center_C + R`;
- Y удерживается на `Y_center_C`;
- Z задаёт высоту слоя;
- C выполняет оборот через `G91 / G1 C360 / G90`;
- E0/E2 включаются только на рабочем обороте C;
- при превышении лимита скорости C программа может снизить линейную F и пересчитать E0/E2.

## Быстрый запуск

### Windows

```bat
run_windows.bat
```

Если обычный запуск не сработал:

```bat
run_windows_ROBUST.bat
```

### Linux

```bash
./run_linux.sh
```

Для переносимой Linux-подготовки:

```bash
./build_linux_portable.sh
./run_linux_PORTABLE.sh
```

## Рекомендуемая проверка перед реальной наплавкой C-режимом

1. Проверить `C+` и `C-` без луча и проволоки.
2. Проверить, что `G91 C360` делает ровно один оборот.
3. Проверить несколько повторных оборотов C360 подряд.
4. Найти реальный центр C в X/Y.
5. Проверить безопасную скорость C.
6. Держать `B=0` для первого опыта.
7. Сначала генерировать TEST до Z10–20 мм.
