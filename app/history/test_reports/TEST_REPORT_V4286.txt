EBAM G-Code Studio v4.2.9.6 REAL C RADIUS LIMIT - TEST REPORT

Base: v4.2.8.5 ROTATIONAL RING SPIRAL.
Goal: add an experimental rotary-table C-axis strategy for rotational vessels / sphere balloons.

Implemented:
1. New rotational vessel strategy: rotary_c_rings.
2. G-code style for rotary C mode:
   - M429 identity kinematics.
   - B fixed, default B=0.
   - X = rotary_c_center_x_mm + current_radius_mm.
   - Y = rotary_c_center_y_mm.
   - Z = layer height.
   - C makes one relative full turn: G91 / G1 C360 / G90.
   - E0/E2 are active only during the C deposition turn.
3. New ProcessSettings fields:
   - rotary_c_center_x_mm
   - rotary_c_center_y_mm
   - rotary_c_direction
   - rotary_c_start_deg
   - rotary_c_b_angle_deg
   - rotary_c_max_deg_min
   - rotary_c_min_radius_mm
   - rotary_c_auto_limit_feed
   - rotary_c_relative_turns
4. UI additions for Чаши/баллоны:
   - Поворотный стол C — кольца B=0
   - settings for C direction, C center X/Y, B angle, start C, C speed limit, min-radius warning, auto-limiting F by C max speed.
5. Rotary C speed calculation:
   C_deg_min = 180 * F_mm_min / (pi * R_mm)
6. If C speed would exceed the configured max and auto-limit is enabled, linear feed is reduced and E0/E2 are recalculated for the actual lower speed.
7. Audit now tracks active C-axis deposition moves and C min/max.
8. Bormash X/Y/Z limit check for rotary mode uses actual X/Y coordinates from the rotary table strategy, not only nominal vessel geometry.
9. New sample files:
   - samples/sample_balloon_rotary_c_table.ngc
   - samples/sample_balloon_rotary_c_table_layers.csv
   - samples/sample_balloon_rotary_c_table_audit.txt
