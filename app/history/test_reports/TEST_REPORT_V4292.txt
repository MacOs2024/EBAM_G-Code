Reason: User found that lowering max C speed changed total time only, while visible F/E0/E2 rows stayed unchanged. Also requested simple-mode Z-step/hatch controls and mutual exclusion between energy input and direct E0 setpoint.

Implemented:
1. Simple mode now exposes:
   - Шаг слоя Z, мм
   - Шаг/ширина между дорожками, мм
   These values go directly into ProcessSettings.layer_height and ProcessSettings.hatch_spacing.

2. Advanced mode E0 logic is now explicit and mutually exclusive:
   - Energy mode: energy fields are editable; E0 is calculated.
   - Current-setpoint mode: energy fields are disabled/greyed; E0 setpoint fields are editable; actual J/mm is recalculated from U, E0 and F.
   - Movement speed F and wire-related controls remain editable.

3. Rotary C max-speed UI calculation is corrected:
   - If rotary C auto-limit is enabled and max C speed is too low, the visible feed F is capped before summary calculations.
   - Then E0, E2, actual energy, time and warnings are recalculated from the capped F.
   - The generator still keeps per-ring C limiting as a second protection layer.
