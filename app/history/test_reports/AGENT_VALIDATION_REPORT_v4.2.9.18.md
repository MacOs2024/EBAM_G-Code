## Ограничение среды проверки

В контейнере отсутствуют `streamlit`, `trimesh`, `shapely`, `ezdxf`; сетевой install недоступен. Поэтому полный Streamlit AppTest и реальные STL/DXF ветки здесь не исполнялись. Логические тесты ядра, не использующие геометрические операции, запускались с импортными заглушками только для отсутствующих модулей. UI-тест исправлен по актуальному API Streamlit AppTest, но его необходимо повторить на Windows/рабочем Python после установки `requirements.txt`.
