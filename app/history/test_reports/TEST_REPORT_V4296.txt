EBAM G-Code Studio v4.2.9.6 REAL C RADIUS LIMIT - TEST REPORT

Base version:
- v4.2.9.5 RING ORDER FIX, supplied by the user.

Problem fixed:
- The UI field "Предупреждать радиус ниже, мм" was named as a warning threshold but was also used as a candidate radius for the UI/global C-feed limiter.
- With warning radius = 18 mm and real cylinder rings around R37-R39 mm, the application could limit F as if the part radius was 18 mm.
- Example old cap: Cmax 750 deg/min at R18 -> F = 235.6 mm/min.

Implemented in v4.2.9.6:
1. Added _rotary_c_radius_limit_info() in app.py.
2. Separated warning radius from C-limit radius:
   - warning radius remains a warning threshold;
   - the C limiter uses real/estimated toolpath Rmin when geometry is known.
3. For parametric rotational vessels:
   - shell wall Rmin = outer_min_radius - wall_thickness + radial_step/2;
   - bottom solid Rmin = radial_step/2;
   - fallback is only used when real radius is unknown.
4. Added UI rows:
   - Радиус, использованный для C-лимита, мм
   - Реальный Rmin траектории, мм
   - Порог предупреждения малого радиуса, мм
   - Источник радиуса для C-лимита
5. Added G-code comment for parametric rotary C paths:
   - (ROTARY_C_REAL_RADIUS_LIMIT: real_Rmin=... warning_below=... source=real_toolpath_radius; warning radius does not clamp F)
6. Core generator still checks every real C-ring and limits feed per ring if required.
