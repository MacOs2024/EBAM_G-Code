# Отчёт проверки EBAM G-code Studio v4.2.9.10

## База сравнения

Исходная версия: `v4.2.9.9 EXPERIENCE PROFILE MERGE`.

Целевая версия: `v4.2.9.10 INDUSTRIAL CONTROL QA`.

## Найденные проблемы и исправления

| № | Было | Стало | Проверка |
|---:|---|---|---|
| 1 | Возможная рекомендация отключать overrides могла быть воспринята как обязательная | Программа не вставляет `M49/M50`; WIRE 100% — только рекомендация | поиск по коду + golden G-code |
| 2 | M68 был единственным вариантом в no-pause | M67 добавлен как опция только после HAL-подтверждения; безопасный fallback M68 | 3 регрессионных сценария |
| 3 | Аудит не моделировал отложенное применение M67 | Добавлена очередь M67 и проверка следующего движения | audit regression |
| 4 | Режим planner был фактически фиксирован | Добавлены G64/machine default/G61/G61.1 и предупреждения | UI + G-code regression |
| 5 | G64 не управлял naive-CAM явно | Добавлен Q, по умолчанию Q=0 | golden G-code |
| 6 | η учитывалась не во всех ветках расчёта | η согласована в E2, объёме, Дж/мм³, стенке и experience recompute | mass/energy tests |
| 7 | Повторный расчёт experience-слоя терял η | `_recompute_layer_after_experience()` исправлен | exact equality regression |
| 8 | Оценка ширины валика повторно делила геометрию на η | Убрано двойное применение η | bead-width regression |
| 9 | Fixed-X no-pause мог молча давать неверную чашу/баллон | Введён контроль изменения радиуса и блокировка | cone rejection test |
| 10 | Имена выгрузок оставались `v4291` | Имя строится из `APP_VERSION` | source inspection + AppTest |
| 11 | Streamlit выдавал deprecation/Arrow warnings | `width="stretch"`, смешанные таблицы приведены к строкам | AppTest без этих предупреждений |

## Проверенные инварианты no-pause

- внешние overrides не изменяются программой;
- M67 не появляется без подтверждения HAL;
- M67 всегда имеет последующее движение;
- финальный OFF выполняется немедленно;
- C возрастает/движется без вставленного `G4` между кольцами;
- Z фиксирован во время основного C360;
- Z меняется только в переходном C+Z;
- радиус не может скрытно меняться при фиксированном X;
- Cfeed не превышает заданный лимит после автоограничения;
- E0/E2/энергия пересчитываются от фактической F;
- η используется одинаково во всех ветках массово-энергетического расчёта.

## Ограничение результата

Тесты подтверждают программную логику и структуру G-code. Они не подтверждают:

- фактическую HAL-привязку M67;
- динамику приводов C/X/Z;
- отсутствие паузы внутри конкретного траекторного планировщика;
- металлургическое качество;
- герметичность шар-баллона;
- безопасность конкретного высоковольтного и вакуумного комплекса.

## Зависимость интерфейса

Для нового параметра `width="stretch"` минимальная версия Streamlit повышена до `1.54`; в `requirements.txt` указано `streamlit>=1.54,<2.0`.
