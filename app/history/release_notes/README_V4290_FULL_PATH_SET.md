# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

## Главное изменение

Во всех режимах и для всех источников теперь доступен единый полный набор стратегий:

- Поворотный стол C — кольца
- Концентрические XY-кольца
- Спираль XY внутри слоя
- Змейкой Y-
- Змейкой Y+
- Змейкой X-
- Змейкой X+
- Параллельно Y-
- Параллельно Y+
- Параллельно X-
- Параллельно X+

## Где доступно

- Простой режим
- Расширенный режим
- STL 3D
- Чаши/баллоны
- Стандартные фигуры
- CSV/DXF контуры

## Важное предупреждение

Для круглых, осесимметричных деталей режимы C-стола, концентрических колец и спирали технологически полезны.  
Для некруглой STL эти режимы являются приближением по радиусам сечения. Если нужно точно повторить сложную форму, использовать обычные X/Y траектории: змейка или параллельные проходы.
