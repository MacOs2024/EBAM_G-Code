# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

Главное изменение: для режима `Чаши/баллоны` добавлены настоящие круговые стратегии.

## Стратегии

1. `Кольца по окружности` — концентрические круговые проходы по слоям. Рекомендуемый стартовый режим для чаш/горшков/баллонов.
2. `Спираль внутри слоя` — архимедова спираль внутри слоя. Меньше стартов и остановов, но требует короткого TEST.
3. `Обычное заполнение сечения` — старое заполнение змейкой/параллельными проходами, оставлено для сравнения и диагностики.

## Новые параметры

- `Радиальный шаг колец/спирали, мм`: 0 = использовать обычный шаг дорожек.
- `Точность окружности, сегментов/оборот`: больше сегментов = ровнее окружность, но больше G-code.
