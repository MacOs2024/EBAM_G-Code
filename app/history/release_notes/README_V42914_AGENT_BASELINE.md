## Безопасность и совместимость

Версия не меняет технологические уставки и не включает новые движения. Расчёт
3-мм стенки является стартовой моделью, а не квалификацией процесса. Горячий
запуск требует отдельного TEST на установке и подтверждения коэффициента η.
