# EBAM G-Code Studio v4.2.9.7 — C CONTINUOUS CONTROLS

Версия добавляет экспериментальные настройки для C-стола, которые нужны для цилиндров/труб на Бормаш:

- режим **«Одно кольцо, C без остановки, переход C+Z»**;
- отключение лишних движений для этого режима: паузы, W-ретракт, Z-hop;
- обязательные параметры режима не вынесены в галочки: луч E0 и проволока E2 остаются включёнными весь непрерывный участок;
- ручной режим подачи проволоки E2:
  - авто по F/Z/шагу;
  - постоянная E2;
  - E2 низ/верх с интерполяцией;
- пересчёт E2, энергии на объём, оценочной толщины стенки и времени при изменении скорости стола.

## Важная логика no-pause режима

Команды строятся как:

```gcode
G91
G1 C360.000 F...
G1 C17.000 Z0.500 F...
G1 C360.000 F...
G1 C17.000 Z0.500 F...
G90
```

Это значит:

1. основное кольцо выполняется на фиксированной высоте Z;
2. C не останавливается после 360°;
3. переход на следующий слой выполняется на коротком секторе C+Z;
4. E0/E2 не выключаются между кольцами.

## Проверка перед наплавкой

Перед реальным запуском обязательно:

1. сухой прогон без E0/E2;
2. проверить направление C+;
3. проверить, что после C360 нет остановки;
4. проверить, что C+Z переход поднимает Z ровно на шаг слоя;
5. первый запуск делать как TEST 10–20 мм.
