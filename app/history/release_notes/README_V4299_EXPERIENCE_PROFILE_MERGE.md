# EBAM G-code Studio v4.2.9.9 EXPERIENCE PROFILE MERGE

Основание: изучен PDF-отчет `EBAM_Gcode_Studio_Continuation_Report_2026_07_09.pdf` из другого чата.

## Что взято полезного

1. Вкладка `Калибровка по фактическому опыту`.
2. Ввод фактической детали: высота, OD, ID, измеренная стенка, целевая стенка, высота начала проблемы, Z-offset.
3. Ввод ручных override: C/feed, Wire, Current отдельно для стабильной и верхней зоны.
4. Формирование зонного профиля:
   - `start_capture`,
   - `stable_wall`,
   - `upper_z_correction`.
5. Защита от слепого копирования высокой E2: если фактическая стенка больше целевой более чем на 30%, E2 пересчитывается от целевой стенки.
6. Коррекция верхнего Z-step по ручному Z-offset.
7. Экспорт `profile.json`, `profile.csv` и краткого отчета.
8. Кнопка `Применить профиль к генератору`.
9. Применение профиля в no-pause C-режиме: Cfeed, E2, Z-step, опционально E0.

## Важная логика

Для no-pause режима E0/E2 по умолчанию включаются один раз, без M68 внутри непрерывного участка. Если профиль задает разные E2/E0 по зонам, приложение переводит их в одно среднее командное значение, чтобы не провоцировать микропаузу. Изменение Cfeed и Z-step по зонам применяется в траектории.
