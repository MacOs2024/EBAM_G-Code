# EBAM G-Code Studio v4.2.9.13 — WIRE FEED SANITY (по кейсу Cylindr_V5)
База: v4.2.9.12. Отчёт по стандарту проекта.

## Проблема (реальный файл с машины)
Cylindr_V5.ngc (сген. v4.2.9.8): manual_constant E2=10.00 мм/с при объёмной
потребности ~4.9-5.0 мм/с для заявленной дорожки 2.25 мм × Z 0.50 мм при F≈294-299.
Переподача ×2.0: подразумеваемая стенка ~4.5 мм; за файл ~51 м лишней проволоки.
Энергетика при этом верная: 27.005 мА → 1620 Вт, 325 Дж/мм. Аудиты файла: ok,
G0 под лучом нет, C-счётчик и завершение корректны. Приложение пропустило
рассогласование МОЛЧА — защиты не существовало.

## Причина
Ручной режим E2 писал значение оператора без сверки с объёмной потребностью
(намеренно допускает и 0 для сухих прогонов), а сверка нигде не выполнялась.

## Решение (advisory, G-code НЕ меняется)
audit_report (единая точка всех генераторов):
1) MANUAL-E2 SANITY: для manual-режимов по каждому слою ratio = E2 / (Z·v·шаг/(A·η));
   шаг = радиальный (кольца/спираль/C) или hatch — единой функцией. Вне [0.6..1.5] —
   предупреждение с точным рецептом: сколько нужно, какая стенка подразумевается,
   и вилка решения («если стенка X мм — цель, приведите шаг/геометрию; иначе E2≈N или auto»).
   E2=0 (сухой прогон) намеренно не трогается. stats: wire_feed_ratio_min/max, флаг.
2) LOW-Z APPROACH: при z_hop<1 мм — предупреждение о XY-подводе на рабочей высоте
   (в V5 z_hop=0: header G0 Z0.000 → переезд к X38.5 по плите).

## Тесты
V5-реконструкция (manual 10): срабатывает ×2.05, стенка ~4.6 мм в тексте. manual 5.0:
молчит (1.03). auto: проверка не применяется. manual 0: молчит. manual 2.0: НЕДОПОДАЧА ×0.41.
Подвод z_hop=0: предупреждение во всех случаях. Файл V5 по-прежнему проходит аудиты.
Их 4 автонабора: failures=0 до и после. Дифф: v42913_core.diff.

## Ограничения
Advisory работает при ГЕНЕРАЦИИ. Для загруженных чужих файлов обратный анализатор
шаг/Z надёжно не знает (разбор V5 выполнен вручную по комментариям файла).
Пороги 0.6/1.5 — стартовые константы.
