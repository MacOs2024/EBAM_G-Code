# EBAM G-Code Studio v4.2.9.17 — SAFE INITIAL Z APPROACH

Новая настройка отделяет начальный безопасный подвод от межпроходного `z_hop_mm`.
Это особенно важно для no-pause C, где межслойный Z-hop может быть отключён, но
начальный XY-переезд всё равно должен проходить над оснасткой.

По умолчанию `safe_initial_approach_enabled=false`, поэтому совместимость сохранена.
При включении генератор до B/C и XY позиционирования выполняет:

`G0 Z<safe_initial_approach_z_mm>`

После XY следует штатный контролируемый `G1 Z<start>`. Абсолютное безопасное значение
зависит от рабочих смещений, оснастки и направления Z конкретного станка. Поэтому
опцию нельзя считать подтверждённой без сухого прогона с отключёнными HV и проволокой.
