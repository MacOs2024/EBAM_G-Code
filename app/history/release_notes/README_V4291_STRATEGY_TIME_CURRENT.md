# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

## Главное изменение

Время изготовления теперь зависит не только от объёма металла, но и от выбранной стратегии траектории.

Раньше предрасчёт мог показывать одинаковое время для разных стратегий, потому что активное время считалось через объём детали и расход проволоки. Физически это частично верно: если объём металла одинаковый, активная наплавка может быть близкой. Но полное время отличается из-за стартов, Z-подходов, W-ретракта, перемычек, C-оборотов и пауз.

Теперь таблица показывает:

- активное время наплавки;
- дополнительное время стратегии;
- количество проходов/стартов;
- количество перемычек/переходов;
- полное время с паузами.

## Добавлена уставка тока E0

Доступны два способа расчёта тепла:

1. **По энергии Дж/мм** — обычный режим. Оператор задаёт энергию, программа рассчитывает ток E0.
2. **По уставке тока E0** — новый режим. Оператор задаёт ток пучка E0, программа рассчитывает фактическую энергию Дж/мм от U, I и скорости F.

Это полезно для экспериментов, где нужно управлять именно током пучка, а не только энергией.

## Где находится

- В простом режиме: раскрывающийся блок `Уставка тока E0, если нужно вручную`.
- В расширенном режиме: checkbox `Задавать ток E0 напрямую вместо энергии Дж/мм`.
