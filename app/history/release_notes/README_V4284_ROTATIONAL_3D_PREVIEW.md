# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

Инженерное приложение для расчёта стартового EBAM G-code под установку Бормаш/LinuxCNC.

## Назначение

Приложение помогает подготовить расчётный G-code для электронно-лучевой проволочной наплавки:

- STL / DXF / CSV / стандартные фигуры → G-code;
- режим чаш, горшков, стаканов, конусов и шар-баллонов;
- расчёт E0/E1/E2/F, слоёв, времени, проволоки и энергии;
- предварительный просмотр геометрии и проходов;
- аудит G-code перед запуском;
- обратный анализ готового G-code;
- профиль Бормаш с проверкой лимитов X/Y/Z;
- всплывающие подсказки `?` для изменяемых параметров.

## Быстрый запуск

### Windows

```bat
run_windows.bat
```

Если обычный запуск не сработал:

```bat
run_windows_ROBUST.bat
```

### Linux

```bash
./run_linux.sh
```

Для переносимой Linux-подготовки:

```bash
./build_linux_portable.sh
./run_linux_PORTABLE.sh
```

## Основные режимы геометрии

- `STL 3D` — загрузка 3D-модели.
- `DXF 2D + высота` — контур + высота.
- `CSV X,Y + высота` — табличный контур + высота.
- `Стандартные фигуры` — прямоугольник, цилиндр и другие базовые формы.
- `Чаши/баллоны` — параметрические чаши, горшки, стаканы, конусы, шар-баллоны.

## Основные выходные файлы

- `.ngc` — основной G-code для LinuxCNC/Бормаш.
- `_layers.csv` — расчёт по слоям: ток, скорость, проволока, энергия, длины проходов.
- `_audit.txt` — аудит безопасности и технологических предупреждений.
- `_settings.json` — параметры, с которыми был создан файл.

## Обязательная проверка перед реальной наплавкой

1. Открыть G-code во внешнем viewer/LinuxCNC preview.
2. Проверить `_audit.txt`.
3. Сделать сухой прогон без пучка и проволоки.
4. Проверить лимиты X/Y/Z/W.
5. Убедиться, что нет G0 при активном E0/E2.
6. Сначала сделать короткий TEST Z10–15 мм.
7. Только после этого запускать полную деталь.
