# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

Версия с дополнительным переводом видимых технических подписей интерфейса.

## Что изменено

- `hatch` в предпросмотре заменён на «рабочие дорожки».
- `link` заменён на «перемычки».
- `contour` заменён на «контуры».
- `preview` заменён на «предпросмотр».
- `fallback` в видимых подписях заменён на «резерв» / «резервный режим».
- `continuous/segmented` в пользовательских подсказках заменены на «непрерывно/посегментно».
- `C-feed` заменён на «скорость C».

## Что оставлено без перевода

- G-code, TEST, JSON и внутренние ключи настроек.
- Служебные имена вроде `hatch_spacing`, `deposition_strategy`, `direction` внутри JSON/кода.

Это сделано специально, чтобы не сломать совместимость сохранённых настроек, G-code-маркеров и внутренней логики.
