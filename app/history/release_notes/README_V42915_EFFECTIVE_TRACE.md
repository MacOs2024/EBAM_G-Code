# EBAM G-Code Studio v4.2.9.15 — REQUESTED → EFFECTIVE TRACE

В непрерывном C-режиме часть пользовательских настроек намеренно преобразуется:
радиальный шаг становится эффективным hatch-шагом, а флаги режима могут обнулить
Z-hop, W-ретракт и паузы. Ранее audit показывал только конечный `ProcessSettings`.

Теперь `stats.requested_effective_changes` сохраняет по каждому реально изменённому
полю три значения: `requested`, `effective`, `reason`. Audit печатает тот же список
отдельным разделом. Если преобразований нет, раздел явно сообщает об этом.

Это изменение наблюдаемости: траектория и технологические уставки не меняются.
