# EBAM G-Code Studio v4.2.9.28 — ДАННЫЕ: ВИЗАРД, ПРОФИЛИ, ЖУРНАЛ (пункты 1, 4, 5)
База: v4.2.9.27. Второй из трёх пакетов улучшений.

## Пункт 1 — Мастер калибровки по одному валику (вкладка «Калибровка», сверху)
Вводишь ширину и высоту валика из TEST + модель перекрытия → мгновенно:
шаг дорожек (TOM 0.738·w / FOM 0.667·w), высота слоя (доля высоты валика, по умолч. 0.9),
перекрытие %, валиков/100мм, соотношение w/h + предупреждения при узком/плоском валике.
Замыкает TEST обратно в параметры. Проверка: валик 4.0×1.7 → шаг 2.95, слой 1.53
(ровно рабочие числа Flange1).

## Пункт 4 — Профили режимов (новая вкладка «Профили и журнал»)
Сохранение текущих настроек как именованный .json-профиль (+ опц. замеры валика, заметка),
загрузка профиля обратно с показом настроек. Толерантно читает и «голый» settings.json.

## Пункт 5 — Журнал наплавок (та же вкладка)
Форма «деталь / SHA / вердикт / фото / размеры план→факт». Автоматически считает Δ
(факт−план) по каждому размеру, копит записи, сохраняет/загружает журнал как .json.
Проверка: R7 OD 165→160.8 даёт Δ −4.2 (как в нашем разборе фото).
