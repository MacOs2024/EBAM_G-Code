# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

## Главное исправление

В режиме `STL 3D` теперь можно не только увидеть рекомендацию по поворотному столу C, но и реально выбрать её в простом и расширенном режимах.

Новый пункт для STL:

- `Поворотный стол C — кольца по STL`

Он создаёт G-code по логике:

- STL режется по слоям Z;
- каждое сечение приближается круговыми радиусами вокруг центра STL;
- X = X центра C + радиус;
- Y = Y центра C;
- C делает `G91 C360`;
- если C-speed превышает лимит, программа может снизить F и пересчитать E0/E2.

## Важно

STL C-режим подходит только для деталей, близких к телам вращения: чаша, баллон, стакан, горшок, тигель. Для сложной несимметричной STL этот режим является приближением, а не точным повторением модели.

## Preview

- обычные STL-режимы показывают рабочие дорожки/стрелки/перемычки;
- STL C-режим показывает круговые C-кольца в выбранном сечении;
- подпись поясняет, что в G-code это будет выполнено через X=центр+R и C360.

## Тепловой профиль

Стартовые энергия, скорость и паузы теперь сильнее зависят от габаритов и типа геометрии. Для круглых высоких STL/чаш/баллонов верхние слои получают более осторожный тепловой профиль.
