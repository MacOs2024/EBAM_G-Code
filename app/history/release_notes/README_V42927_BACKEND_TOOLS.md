## Новый модуль ebam_gcode_studio/gcode_tools.py (read-only, ничего не меняет в G-code)
### Пункт 2 — Постпроверка G-code (светофор) — post_generation_check()
Показывается СРАЗУ после генерации, развёрнутый блок «🚦 Проверка G-code»:
- Ток пучка E0: max vs лимит (🔴 если есть ход выше)
- Подача E2: max vs граница + счётчик колец E2>=45 (зона выхода проволоки из ванны)
- Плотность энергии QV: min, 🔴 при <=42 (полевой порог отказа R6), 🟡 ниже целевого 55
- Скорость стола C: диапазон vs лимит
- Мощность пучка: min vs порог проплава
- Быстрые ходы G0 под лучом: 🔴 если есть перемещение с включённым лучом
- Тепловые выдержки: сколько и суммарно
### Пункт 11 — Вмерзание кончика проволоки — wire_freeze_check()
Ищет длинные G4 (>60 с) без W-ретракта рядом → 🔴 «кончик может вмёрзнуть».
На реальном R8-оригинале ловит все 16 незащищённых выдержек.
### Пункт 6 — Сравнение двух G-code — compare_gcode()
Во вкладке «Предпросмотр» → «🔬 Сравнить с другим G-code»: второй загрузчик,
таблица A/B/Δ по 12 полям (кольца, время, E0/E2/QV max-min, C, выдержки, рестрайки,
W-ходы). Идентичные файлы отмечаются явно (как было с «Cloude»-файлами: identical=True).
