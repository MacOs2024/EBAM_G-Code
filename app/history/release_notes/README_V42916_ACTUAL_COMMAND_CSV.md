# EBAM G-Code Studio v4.2.9.16 — ACTUAL E0/E2 COMMAND TRACE

В no-pause режиме расчётные значения слоя могут изменяться по высоте, но без зонных
обновлений G-code один раз отправляет усреднённые E0/E2. Старый `layers.csv` показывал
только расчётные `current_ma` и `wire_mm_s`, поэтому его можно было неверно прочитать
как журнал фактических команд.

Новые столбцы:

- `actual_e0_command_ma`, `actual_e2_command_mm_s` — реально отправляемая уставка;
- `analog_command_mode` — M68/M67 и режим once-average/zone;
- `analog_command_update` — 1 только перед фактическим обновлением.

Старые столбцы сохранены без переименования для обратной совместимости.
