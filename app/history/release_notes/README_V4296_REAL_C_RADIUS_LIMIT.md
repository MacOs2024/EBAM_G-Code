# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

## Что исправлено

В v4.2.9.5 поле `Предупреждать радиус ниже, мм` могло фактически ограничивать F при включённом `Автоограничивать F по лимиту C`. Из-за этого цилиндр с реальными кольцами около R37–R39 мм мог считаться как будто радиус всего 18 мм, и скорость F падала слишком сильно.

В v4.2.9.6 логика разделена:

- `Предупреждать радиус ниже, мм` — только предупреждение о малом радиусе.
- C-ограничитель F использует реальный/оценочный минимальный радиус траектории, если геометрия известна.
- Для неизвестной STL/универсальной геометрии до секционирования поле 18 мм может использоваться как осторожный fallback, и это явно показывается в таблице.

## Пример

Для цилиндра:

```text
C max = 750 град/мин
warning radius = 18 мм
реальный Rmin ≈ 37 мм
```

Старое поведение:

```text
F cap = 750 × π × 18 / 180 = 235.6 мм/мин
```

Новое поведение:

```text
F cap = 750 × π × 37 / 180 = 484.3 мм/мин
```

Генератор всё равно проверяет каждое реальное C-кольцо отдельно и не позволяет Cfeed превысить лимит.

## Новые строки в таблице

- `Радиус, использованный для C-лимита, мм`
- `Реальный Rmin траектории, мм`
- `Порог предупреждения малого радиуса, мм`
- `Источник радиуса для C-лимита`
