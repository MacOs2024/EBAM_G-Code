# EBAM G-code Studio v4.2.9.10 — INDUSTRIAL CONTROL QA

Версия создана на базе `v4.2.9.9 EXPERIENCE PROFILE MERGE` после сопоставления приложения с открытой документацией NASA EBF³, Sciaky EBAM/IRISS и официальной документацией LinuxCNC по `M67`, `M68`, `G61/G61.1/G64`.

## Главное правило по внешним overrides

Программа **не вставляет `M49` и `M50`**, не блокирует и не сбрасывает операторские overrides. Ручная регулировка остаётся доступной.

Рекомендация `WIRE override = 100%` показывается только как условие воспроизводимой калибровки. Это не объявляется универсальной функцией LinuxCNC, поскольку связь ручки WIRE с приводом подачи зависит от HAL/конфигурации конкретной установки.

## Основные изменения

### 1. Управление аналоговыми E0/E2

- По умолчанию сохранён совместимый с текущей установкой режим `M68`.
- Добавлен опциональный синхронный режим `M67`.
- `M67` разрешается только после явного подтверждения: `Подтверждаю поддержку M67 в HAL`.
- Если подтверждения нет, генератор автоматически возвращается к `M68`.
- Финальное отключение E0/E2 всегда выполняется через немедленный `M68`, потому что `M67` без следующего движения не применяется.

### 2. Планировщик траектории

Добавлены режимы:

- `G64 P/Q — плавное сопряжение`;
- `Режим станка по умолчанию`;
- `G61 — точная траектория`;
- `G61.1 — точная остановка`.

Для `G64` можно задавать `P` и `Q`. По умолчанию `Q=0`, чтобы не упрощать короткий переход `C+Z` через naive-CAM.

При `G61/G61.1` в no-pause C-режиме приложение выдаёт предупреждение о возможном замедлении/остановке на границах блоков.

### 3. Коэффициент осаждения η

Добавлен параметр `deposition_efficiency` в расчёты:

- автоматической E2;
- фактически осаждённого объёма;
- `Дж/мм³`;
- оценки толщины стенки;
- калибровочного профиля;
- повторного расчёта слоя после применения профиля.

`η=1.0` сохранено как совместимое старое поведение, но UI предупреждает, что это некалиброванная верхняя оценка.

### 4. Защита геометрии no-pause C

Режим с фиксированным X и непрерывными кольцами теперь разрешён только для почти постоянного радиуса.

Если радиус чаши/баллона меняется по высоте сильнее заданного допуска, генерация блокируется с объяснением. Это предотвращает прежний риск: интерфейс показывал меняющийся диаметр, но no-pause G-code мог физически оставить X постоянным и изготовить неверную геометрию.

Для меняющегося радиуса следует использовать отдельные C-кольца с перестановкой X либо отдельно квалифицированную синхронную траекторию X+C+Z.

### 5. Зонный профиль калибровки

- Зонные E0/E2 теперь могут реально обновляться на границах зон.
- При подтверждённом HAL используется `M67` перед следующим кольцом.
- В совместимом режиме остаётся `M68` и выдаётся предупреждение, что он может нарушать blending.
- Если зонные обновления отключены, применяется усреднённое значение для непрерывности.

### 6. Статический аудит G-code

Аудит теперь:

- понимает очередь `M67`;
- применяет значение в начале следующего движения;
- обнаруживает `M67` без последующей команды движения;
- считает `M67/M68`;
- обнаруживает немедленные обновления `M68` при активной наплавке;
- фиксирует `G61/G61.1/G64`;
- предупреждает о сочетании exact-path и активного C.

### 7. Исправления интерфейса

- Добавлен блок контроллера в расширенном режиме.
- Все предупреждения по M67/M68, G61/G64 и overrides сформулированы как рекомендации с учётом machine-specific конфигурации.
- Исправлены устаревшие имена скачиваемых файлов `v4291`: теперь используется текущий тег `v42910`.
- Заменён устаревающий Streamlit-параметр `use_container_width` на `width="stretch"`.
- Таблицы со смешанными типами преобразуются в строки и больше не вызывают Arrow-сериализационные предупреждения.

## Что намеренно не сделано

- В G-code не добавлены `M49/M50`.
- Ручные overrides не заблокированы.
- `M67` не включён по умолчанию.
- Не заявлена автоматическая поддержка M67 конкретной установкой без проверки HAL.
- Не реализован автоматически «истинный» X+C+Z для шар-баллона: без проверки кинематики, planner и HAL это было бы небезопасным предположением.

## Перед реальной установкой

1. Сначала выполнить dry run без луча и проволоки.
2. Проверить, принимает ли стойка `G64 P... Q0`.
3. Не включать M67, пока не подтверждены HAL-связи `motion.analog-out-N` с E0/E2.
4. Проверить, что C не тормозит на `C360 → C+Z`.
5. Выполнить короткий горячий тест 10–20 мм.
6. Измерить высоту слоя, ширину/толщину стенки и уточнить η.
7. Только после этого применять калибровочный профиль к длинной детали.

> Программная проверка не заменяет квалификацию режима на конкретной установке, проверку вакуума, высоковольтных блокировок, охлаждения и аварийного останова.
