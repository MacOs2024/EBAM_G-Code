# EBAM G-Code Studio v4.2.9.22 — CV ВО ВСЕХ ПУТЯХ + ЧЕСТНАЯ ОЦЕНКА + ФИКС СБОРКИ
База: v4.2.9.21. Отчёт по стандарту проекта. Разбор реального инцидента 17.07 (Flange1_v2, 50 ч).

## Причинная цепочка инцидента (доказана вскрытием ebam_result_v42921_FULL)
1) Фланец маршрутизируется НЕ через _generate_mesh_rotary_c, а через специальный
   путь чаши/баллона (_generate_special_paths_from_polygon_provider) — формат
   (SPECIAL_PATH / ROTARY_C_RING, linearF=const). Этот 4-й цикл сознательно не был
   пропатчен в v4.2.9.21 → галочка CV (в settings была True!) игнорировалась.
2) Глобальный зажим F по fallback-радиусу 18 мм (_apply_rotary_c_feed_limit_to_settings)
   душил F до 188.5 мм/мин ещё ДО генерации → отравлены E2/энергия/время в сводке.
3) Текст моей же ошибки «0.6–0.8 ширины валика» читался как «0.6 мм» → оператор
   поставил радиальный шаг 0.6 → 1988 колец → 50 ч 39 мин.
4) exe-сборка (PyInstaller) не включала flange_family_generator → ModuleNotFoundError.
5) UX: уставка тока 21.9 < нижнего лимита 25 → ток поднят до 25, энергия уехала на 477 Дж/мм.

## Исправления
1) ЦИКЛ-4: _rotary_c_ring_kinematics встроена в специальный путь — CV теперь работает
   на реальном маршруте фланца (по-кольцевые C 600→450, E2 в комфорте, pitch-уплотнение).
2) При включённом CV глобальный зажим F ПРОПУСКАЕТСЯ (кинематика лимитирует по-кольцево);
   в c_limit_info добавлен маркер cv_mode + пояснение.
3) Оценщик времени в CV-режиме зовёт ТУ ЖЕ _rotary_c_ring_kinematics — оценка до
   генерации совпадает с генератором по построению.
4) Текст ошибки радиального шага переписан: «ДОЛЯ ширины: для валика 4 мм это 2.4–3.2 мм;
   обычно ставят РАВНЫМ „Шагу дорожек“» + подсказка с текущим значением hatch_spacing.
5) EBAM_Gcode_Studio.spec: добавлен hiddenimport 'flange_family_generator'.
   Пересобрать exe: pyinstaller EBAM_Gcode_Studio.spec  (или запускать из исходников:
   streamlit run app.py — модуль найдётся и без пересборки).

## Доказательства
Их 9 не-STL наборов + time_target_levers + rotary_c_constant_velocity: failures=0.
Проекция его фланца (радиусы слоёв из ЕГО ngc, шаг 2.58, CV): 32 слоя, 483 кольца
(было 1988), активная 5.39 ч + сервис ~12 мин ≈ 5.6 ч — В ЦЕЛИ ≤6 ч; E2 ≤ 29 мм/с.
Диффы: v42922_core.diff / v42922_app.diff / v42922_spec.diff.

## Как получить правильный файл (оператору)
Радиальный шаг = 2.58 (равен «Шагу дорожек»); режим ЭНЕРГИИ 280/260 Дж/мм при лимитах
E0 25–40 (галку «ток напрямую» снять — тогда «и энергия, и лимиты тока» работают вместе);
CV включён, комфорт 29, min pitch 0.6. Перегенерировать; смотреть «время по фактическим
траекториям» ≈ 5–5.7 ч. Далее стандарт: сухой прогон → TEST → деталь.

## Ограничения (честно)
- Специальный путь остаётся ОТДЕЛЬНЫМИ кольцами (перенос no-pause-движка на него —
  следующий шаг; на время цели уже не влияет, влияет на рестрайки/качество шва).
- Реальная генерация — на Windows (STL/trimesh); проекция времени ±10–15%.
- E2 на крошечных верхних кольцах ступицы мала по построению (мало металла нужно) — норма.
