# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

## Что исправлено

1. В простом режиме добавлены ручные поля:
   - `Шаг слоя Z, мм`
   - `Шаг/ширина между дорожками, мм`

2. В расширенном режиме логика энергии и уставки E0 стала взаимоисключающей:
   - если работает расчёт по энергии, поля Дж/мм доступны, а E0 считается;
   - если включена уставка E0, поля энергии заблокированы, а фактическая энергия пересчитывается от тока, напряжения и скорости.

3. При ограничении максимальной скорости C теперь меняется не только время:
   - ограничивается видимая скорость F;
   - пересчитываются E0, E2, энергия и предупреждения;
   - генератор по-прежнему дополнительно защищается по каждому C-кольцу.

## Как проверить

См. `TEST_REPORT_V4292.txt` и сравните режим `Поворотный стол C — кольца` при C max 10000 и 300 град/мин.
