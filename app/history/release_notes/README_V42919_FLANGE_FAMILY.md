# EBAM G-code Studio v4.2.9.19 — FLANGE-FAMILY

Новый отдельный режим `Flange-family R6 (STL → C-кольца)` строит комплект
G-code для осесимметричных фланцев одного технологического семейства. Размеры
не зашиты в программу: при изменении отверстия, наружного диаметра, общей
высоты, высоты уступа или конусности профиль повторно извлекается из STL.

## Что делает приложение

1. Загружает STL, объединяет совпадающие вершины треугольников без изменения
   координат и проверяет топологию.
2. Автоматически выбирает ось высоты по равенству двух поперечных габаритов;
   оператор может принудительно выбрать X, Y или Z.
3. Центрирует ось вращения и переносит низ детали на рабочий Z=0.
4. Строит сечения, восстанавливает внутренний и наружный радиусы и находит
   скачки профиля. Найденные уступы становятся точными границами слоёв.
5. Распределяет слои по зонам около заданной высоты слоя.
6. Для каждого слоя вычисляет `N = ceil((Rout−Rin)/pitch_max)` и размещает
   центры дорожек так, чтобы покрыть весь annulus. Все слои идут от внутреннего
   радиуса к наружному, только C+.
7. Интегрирует объём слоя по Z и делит его на длину колец и горячих радиальных
   связок. Из площади осаждения рассчитываются время, C, E2, E0 и энергия.
8. Учитывает экспериментальный запас тока для HMI-развёртки 300 Гц, X=10%,
   Y=10%. Параметры развёртки выводятся в заголовок и чек-лист; вымышленные
   M-коды управления разверткой не добавляются.
9. Перед первой синхронной командой E0/E2 вставляет обязательный `M0`: оператор
   подтверждает 300 Гц, X=10%, Y=10% и оба override=100%. Это время включено в
   плановую оценку, но исключено из детерминированного времени движений.
10. Блокирует горячий ZIP, если нарушены геометрия, баланс объёма, направление,
   E0/E2/C, окно времени 4–6 ч или синтаксис круглых комментариев LinuxCNC.
11. Вместе с горячим кандидатом создаёт полный dry-run E0=E2=0, короткие тесты,
    CSV расписания, JSON настроек/проверок, алгоритм и SHA-256 manifest.

## Базовые ограничения режима

- E0 горячий: 25,0…39,5 мА при жёстком пределе 40 мА;
- E2: не более 49,5 мм/с при жёстком пределе 50 мм/с;
- C: 450…599,5 град/мин при жёстком пределе 600 град/мин;
- развёртка HMI: концентрические окружности, 300 Гц, X=10%, Y=10%;
- направление каждого слоя: внутренний радиус → наружный;
- плановое окно времени: 4…6 ч.

## Проверенная эталонная геометрия Flange1

Для `Flange1(2).STL` приложение обнаруживает исходную ось Y, OD=164 мм,
ID=40 мм, H=47,5 мм и уступ Z=23 мм. При настройках по умолчанию получается
32 слоя, 426 колец и плановое время около 5,107 ч. Диапазоны: E0=25…37,95 мА,
E2=13,201…49,5 мм/с, C=564,718…599,5 град/мин.

Регрессионная проверка также масштабирует модель до OD≈167,28 мм,
ID≈40,80 мм, H≈46,55 мм. Без изменения программного алгоритма получено
31 слой, 438 колец и около 5,174 ч.

## Порядок работы

1. Запустить `run_windows_ROBUST.bat`.
2. Выбрать `Flange-family R6 (STL → C-кольца)`.
3. Загрузить STL и проверить найденные OD, ID, H, ось и таблицу зон.
4. Если автоматическое распознавание неверно — выбрать ось вручную или добавить
   границу Z через поле `Доп. границы Z`.
5. Убедиться, что все статические проверки имеют статус PASS.
6. Скачать ZIP и сначала выполнить полный dry-run с физически отключёнными HV и
   приводом проволоки.
7. При остановке `M0` подтвердить развёртку 300 Гц, X/Y=10% и override=100%.
8. На отдельной заготовке выполнить короткие квалификационные тесты; измерить
   ширину/высоту валиков, сплавление, геометрию и тепловое состояние.
9. Только после подтверждения HAL, координат, фокуса, развёртки и технологии
   рассматривать полный горячий файл как квалификационный кандидат.

PASS означает статическую согласованность расчёта, а не готовую производственную
технологическую карту.
