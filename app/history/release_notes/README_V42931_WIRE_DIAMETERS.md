# EBAM G-Code Studio v4.2.9.31 — НЕРЖАВЕЙКА Ø1.6 / 2.0 / 2.5 мм
База: v4.2.9.30. По запросу оператора: добавить толстые проволоки, чтобы расчёты
корректировались под выбранный диаметр.

## ГЛАВНОЕ О ФИЗИКЕ
QV (Дж/мм³) — энергия на ОБЪЁМ наплавленного металла, от диаметра проволоки напрямую
не зависит. Поэтому проверенные полем 72/63 Дж/мм³ взяты как СТАРТОВАЯ ТОЧКА для всех
диаметров. Всё, что от диаметра ЗАВИСИТ, пересчитывается автоматически:

  сечение проволоки   A = pi*d²/4      растёт КВАДРАТИЧНО
      1.2 -> 1.131 мм²   1.6 -> 2.011   2.0 -> 3.142   2.5 -> 4.909  (в 4.34 раза)

  потолок подачи      E2max = U*Imax/(QV*A)   падает как 1/A
      при 40 мА: 1.2 -> 39.8 мм/с | 1.6 -> 22.4 | 2.0 -> 14.3 | 2.5 -> 9.2

ОГРАНИЧЕНИЕ ЗАДАЁТ ЛУЧ, А НЕ МЕХАНИЗМ ПОДАЧИ. Луч при 40 мА и QV=55 расплавляет не
более 43.6 мм³/с металла; толстая проволока даёт этот объём при пропорционально
МЕНЬШЕЙ линейной подаче. Отсюда предел подачи для толстой проволоки НИЖЕ, а не выше.
Сходимость: расчётный потолок для Ø1.2 составил 39.8 мм/с — практически совпал с
эмпирическим пределом 40 мм/с, который стоял в программе с самого начала.

  границы слоя        0.30*d .. 1.40*d
      1.2 -> 0.36..1.68 | 1.6 -> 0.48..2.24 | 2.0 -> 0.60..2.80 | 2.5 -> 0.75..3.50

## ЧТО ДОБАВЛЕНО
1. Три профиля: stainless_steel_16/20/25_wire. В выпадающем списке появляются сами.
2. Функции wire_area_from_diameter(), max_wire_feed_for_beam(), layer_height_bounds_for_wire().
3. Рекомендатор при смене материала пересчитывает предел подачи и границы слоя от диаметра.
4. Флаг field_calibrated: True только у Ø1.2. Для остальных интерфейс показывает
   предупреждение о необходимости калибровочного валика и справку с расчётным
   потолком подачи для выбранного диаметра.
5. Строка в аудите, если высота слоя выше проверенных на машине 1.53 мм.

## ЧЕСТНЫЕ ОГОВОРКИ (важно)
- Профили 1.6/2.0/2.5 НЕ подтверждены наплавками. QV взята от Ø1.2. С ростом диаметра
  растут теплоёмкость входящего металла, площадь контакта с ванной и инерция
  расплавления — реальная QV может потребоваться ВЫШЕ. Первый валик на новом диаметре
  делать только через «Калибровку» с замером ширины и высоты.
- Слои выше 1.53 мм на этой машине не проверялись. Для Ø2.5 расчёт допускает до 3.5 мм —
  это расчётная, а не проверенная величина; аудит про это предупреждает.
- Реальные пределы механизма подачи по толстой проволоке неизвестны. Показанные потолки
  — чисто энергетические (что осилит луч). Если механизм слабее, ставьте свой предел вручную.
- Streamlit визуально не проверялся: справка и предупреждение по материалу — на Windows.
