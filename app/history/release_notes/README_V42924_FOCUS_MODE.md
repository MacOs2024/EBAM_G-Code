## Поведение при ВКЛЮЧЁННОЙ галочке «Подогнать режим под желаемое время»
1. Плашка «🎯 Режим целевого времени…» — ориентир, куда смотреть.
2. Вердикт одной строкой (зелёный/жёлтый/красный): «Цель X → получится Y (±Z%)» — как был.
3. Таблица «Применено» + НОВАЯ таблица «Итог режима под целевое время»:
   радиальный шаг; ПОДАЧА ПРОВОЛОКИ E2 низ/верх (с контрольной границей) — то, чего не
   хватало; ток в G-code (с лимитом); мощность пучка (с порогом проплава); C требуется/
   разрешено; время: активная наплавка / паузы+тепловые выдержки / ПОЛНОЕ.
4. Спрятано в свёрнутые блоки: «Анализ геометрии», «📊 Все расчётные значения»,
   «Подробности и рекомендации» (мягкие советы тюнера), синяя справка C-ограничителя,
   строка стратегии, предупреждение про контурные проходы.
5. ВСЕГДА на виду (безопасность, не прячется): красный/жёлтый гейт мощности проплава,
   критические сообщения тюнера (подача выше контрольной границы, «в цель не уложиться —
   минимум N ч, разрешите…»), предупреждение C-лимита при реальном зажиме F, ошибки тока.
   Дубль предупреждения о подаче устранён (раньше висело дважды).
6. Зелёный гейт в фокус-режиме сжимается до одной строки «✅ …».
