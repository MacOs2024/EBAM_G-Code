# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

## Что изменено

Исправлен порядок генерации колец для режимов тел вращения и C-стола.

Было:

```text
наружное кольцо -> внутреннее кольцо
```

Стало:

```text
внутренний диаметр -> наружный диаметр
```

Для сплошного донца это означает:

```text
центр / малый радиус -> наружный радиус
```

Для чаши, горшка, шар-баллона или кольцевой стенки это означает:

```text
внутренняя стенка -> наружная стенка
```

## Где исправлено

- `Поворотный стол C — кольца`
- `Концентрические XY-кольца`
- STL/секционные C-кольца
- параметрические `Чаши/баллоны`
- generic polygon special paths

## Как увидеть исправление в G-code

В G-code теперь добавляется маркер:

```gcode
(RING_ORDER: inner_to_outer; ...)
```

В строках `ROTARY_C_RING` радиус должен идти по возрастанию:

```gcode
RING=1/... R=малый
RING=2/... R=больше
RING=3/... R=ещё больше
```
