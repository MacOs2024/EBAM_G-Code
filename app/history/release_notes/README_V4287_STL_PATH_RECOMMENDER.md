# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

## Что исправлено

В простом и расширенном режимах для обычных источников, включая STL, теперь используется единый явный список проходов:

- Змейкой Y-
- Змейкой Y+
- Змейкой X-
- Змейкой X+
- Параллельно Y-
- Параллельно Y+
- Параллельно X-
- Параллельно X+

Выбор на экране напрямую задаёт `direction` (направление) и `deposition_strategy` (стратегия наплавки) в генераторе.

## STL-рекомендация

Для загруженного STL приложение показывает рекомендуемый стартовый план проходов по пропорциям модели. Если STL выглядит как осесимметричная/баллонная деталь, приложение предупреждает, что технологически лучше задать её через режим `Чаши/баллоны`, где доступны специальные кольца, спираль и поворотный стол C.

## Предпросмотр

Предпросмотр теперь меняется при изменении режима:

- непрерывная змейка показывает перемычки пунктиром;
- посегментные параллельные проходы не показывает перемычки;
- стрелки на дорожках показывают фактическое направление Y-/Y+/X-/X+.
