# EBAM G-Code Studio v4.2.9.12 — SEAM SCATTER + η CROSS-CHECK + M67 HAL KIT
База: v4.2.9.12 = мой v4.2.9.11 (порог проплава, калибровка, контекстная сводка) + три идеи.
Отчёт по стандарту передаточного PDF.

## 1. Рассеивание шва (дефект №2 из PDF: «сильный вертикальный шов»)
ПРИЧИНА: в режиме отдельных C-колец каждое кольцо стартует с одного угла — старт/стоп
накапливается на одной образующей. (В no-pause шов и так смещается углом перехода.)
БЫЛО: G0 X/Z → M68 E0 → кольцо. СТАЛО: новое поле rotary_c_seam_scatter_deg (0=выкл,
рекомендация 137.5° золотой угол): перед КАЖДЫМ включением луча — относительная
репозиция G91/G0 C±scatter/G90 при ВЫКЛЮЧЕННОМ луче, знак по направлению C.
Только relative-turns режим; валидация |scatter|<180.
ДОКАЗАНО: 40 колец = 40 репозиций; audit ok, g0_active=0 и g0_active_c=0 (репозиция
при луче OFF); scatter=0 даёт байт-в-байт легаси-поведение; «137,5» коэрсится; старый
settings.json грузится с дефолтом 0.

## 2. Сверка η: валики ↔ деталь
estimate_eta_from_wall(): η = wall·z_step·v/(A_wire·E2) — инверсия формулы PDF 8.2.
ДОКАЗАНО на числах PDF: wall=1.0, z=0.5, F=750, E2=5.526 → η=1.000 точно.
eta_cross_check(): вердикт agree/disagree (порог 20%), диагностика в какую сторону
(потери на детали vs ошибка измерения валиков), рекомендация среднего только при
сходимости — вслепую не усредняет. UI: экспандер на странице калибровки; η из
матрицы валиков подставляется автоматически.

## 3. Комплект квалификации M67 по HAL (задача 17.2.3 из PDF)
generate_m67_hal_check_kit(): dry-run .ngc (M68 vs M67 на E0 и E2, крошечные Q,
короткие ходы; КАЖДЫЙ M67 сопровождён движением; финальный OFF — немедленный M68)
+ русский чек-лист PASS-критериев (пин меняется в паузу для M68; только на старте
движения для M67; очередь из двух M67). Комплект намеренно СОДЕРЖИТ M67 — это сама
процедура подтверждения; продакшн-генераторы по-прежнему гейтятся на
machine_m67_confirmed, который автоматически НЕ включается.
ДОКАЗАНО: инварианты кита (4×M67, каждый с последующим движением, финал M68) — прогоном.
