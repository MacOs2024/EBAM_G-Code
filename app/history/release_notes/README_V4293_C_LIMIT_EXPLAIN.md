# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

Эта версия сделана от базы v4.2.9.2. Предыдущий экспериментальный вариант `WIRE_FEED_FIX` исключён из линии версий.

## Что изменено

- Для режима `Поворотный стол C — кольца` добавлено явное объяснение работы ограничителя F по скорости C.
- В расчётной таблице появились строки:
  - `Ограничитель F`;
  - `F заданная низ/верх, мм/мин`;
  - `F фактическая низ/верх, мм/мин`;
  - `C требуется низ/верх, град/мин`;
  - `C разрешено, град/мин`;
  - `Радиус проверки C, мм`.
- Если C-ось ограничивает скорость, приложение показывает предупреждение: расчёт E0/E2/энергии/времени выполняется по фактической F.
- Если автоограничение выключено, приложение предупреждает, что расчёт идёт по заданной F и перед реальным запуском нужно проверить C-скорость.

## Что не менялось

- Математика подачи проволоки не менялась относительно v4.2.9.2.
- Генератор G-code не заменялся экспериментальным `WIRE_FEED_FIX`.
- Эта версия нужна, чтобы оператор видел причину ограничения F, а не принимал его за ограничение проволоки.

## Главная логика

Для C-стола скорость по окружности связана с радиусом:

```text
C град/мин = 180 × F мм/мин / (π × R мм)
```

Если требуемая скорость C выше разрешённой, приложение снижает фактическую F. После этого E0, E2, энергия и время считаются уже от фактической F.
