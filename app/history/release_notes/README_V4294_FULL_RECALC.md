# EBAM G-Code Studio v4.2.9.6 — REAL C RADIUS LIMIT

Эта версия исправляет главную логику C-ограничителя: если оператор меняет `Максимальная скорость C, град/мин` и включает `Автоограничивать F по лимиту C`, приложение пересчитывает всю технологическую цепочку по фактической скорости:

- F заданная / F фактическая;
- E2 до ограничителя / E2 фактическая;
- E0 до ограничителя / E0 после ограничителя;
- энергия Дж/мм;
- энергия Дж/мм³;
- время и предупреждения.

Генератор G-code дополнительно проверяет каждое C-кольцо по реальному радиусу. Если конкретное кольцо требует скорость C выше лимита, линейная скорость для этого кольца уменьшается, а E0/E2 пересчитываются по новой скорости.

Проверено: см. `TEST_REPORT_V4294.txt`.
