# EBAM G-Code Studio v4.2.9.18 — CYLINDR V5 3-MM QUALIFICATION PACK

Версия завершает агентный цикл из пяти итераций. Скрипт
`generate_cylindr_v5_3mm_qualification_pack.py` читает исходный JSON V5,
сохраняет геометрию/скорости/ток и строит короткие 10-мм файлы:

- DRY motion: E0=0, E2=0;
- LOW: расчётная E2 для 3 мм × 0.90;
- NOMINAL: расчётная E2 для 3 мм;
- HIGH: расчётная E2 для 3 мм × 1.10.

Для исходных F=299.433 мм/мин, Z=0.5 мм, проволоки 1.2 мм и η=1.0
номинальная модель даёт E2≈6.619 мм/с. Это модель сохранения объёма, не
квалифицированный технологический режим. Пакет специально фиксирует
`hot_run_authorized=false` и неподтверждённые проверки станка.
