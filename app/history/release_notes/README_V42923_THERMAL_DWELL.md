# EBAM G-Code Studio v4.2.9.23 — АДАПТИВНЫЕ ТЕПЛОВЫЕ ВЫДЕРЖКИ («мин. цикл слоя»)
База: v4.2.9.22. По запросу оператора; параметры по его указанию: цикл 3 мин, «по 2 минуты
на слой ступицы» реализовано как ПОЛ выдержки 120 с.

## Полевые данные (основание)
R6 (flange-family): 16 тепловых выдержек 116–189 с, суммарно 41.3 мин — ТОЛЬКО на коротких
слоях ступицы; длинные слои диска шли без пауз (сами остывают ~15–20 мин между проходами).
R7 (общий STL-путь v4.2.9.21): выдержек 0 — в этом пути логики никогда не было, плюс стояла
галочка «Отключить паузы». Ступица без выдержек = перегрев тонкого столбика, оплывание,
зарастание отверстия.

## Формула
Если слой закончился быстрее минимального цикла: dwell = max(цикл − t_слоя, пол), иначе 0.
Дефолты: цикл 3.0 мин, пол 120 с (оба редактируемые). На диске (~19 мин/слой) — ноль
автоматически; на ступице (~2 мин/слой) — ровно ~2 мин, как в R6. Пауза ставится G4 в конце
слоя, луч и проволока в этот момент уже выключены (покольцевые пути).

## Где встроено
- ProcessSettings: thermal_min_layer_cycle_enabled / _min (3.0) / thermal_min_dwell_s (120).
- _thermal_dwell_for_layer() + эмиссия «G4 … (THERMAL_DWELL Lk: adaptive…)» во ВСЕХ ТРЁХ
  покольцевых генераторах: STL mesh, параметрический, СПЕЦИАЛЬНЫЙ ПУТЬ ЧАШИ/ФЛАНЦА
  (реальный маршрут Flange1). Время слоя считается по фактическим кольцам слоя.
- Аудит: строка «ТЕПЛОВЫЕ ВЫДЕРЖКИ: N шт, суммарно M.M мин (цикл…, пол…)».
- Оценщик времени (no-pause C ветка): равномерная аппроксимация выдержек в pause_s.
- UI: блок «Тепловая выдержка между слоями (адаптивно)» в настройках C-стола (под CV):
  галочка + «Мин. цикл слоя, мин» + «Мин. выдержка при срабатывании, с».

## Доказательства
thermal_dwell_regression_test: 11 проверок (хелпер: выкл/длинный слой→0, короткий→max(gap,пол);
генерация: 4 быстрых слоя → 4 выдержки по 120 с; числа аудита совпадают с файлом; выкл → 0) —
все зелёные. Полная регрессия: 10 наборов failures=0. Дефолт выключен → старое поведение
байт-в-байт. Диффы: v42923_core.diff / v42923_app.diff.

## Проекция Flange1 (шаг 2.58, CV, выдержки ВКЛ 3 мин/120 с)
Диск 15 слоёв ×~19 мин → 0 пауз; ступица 17 слоёв → 17 × 2 мин = 34 мин.
Итого ≈ 5.6 ч + 0.57 ч ≈ 6.2 ч. Если критично уложиться в 6.0 — пол 60 с даёт ≈ 5.9–6.0 ч.

## Ограничения (честно)
- В no-pause-путях (C/Z-переходы без гашения) выдержка НЕ вставляется — там она требует
  цикла гашения/розжига луча (рестрайк на паузу); перенос — следующий шаг. Маршрут твоего
  фланца (спец-путь, отдельные кольца) ПОКРЫТ.
- Независимого валидатора в этой линии кода нет — выдержки видны в аудите и в самом файле
  (G4 ≥ 10 с); «время по фактическим траекториям» суммирует их автоматически.
- Оценка ДО генерации — равномерная аппроксимация (может не увидеть паузы ступицы при
  разной длине слоёв); точные числа — в аудите после генерации.
- Порог межслойной температуры мы не измеряли: 3 мин/120 с — полевая калибровка по R6;
  истину покажет TEST ступицы с пирометром.
