# EBAM G-Code Studio v4.2.9.25 — «ПРИНЯТЬ КАК БАЗУ И КОРРЕКТИРОВАТЬ»
База: v4.2.9.24 FOCUS MODE. По запросу оператора: «база посчитана — оттуда корректирую».

## Что добавлено
1. КНОПКА «📌 Принять как базу и корректировать» в панели подгонки времени (под таблицей
   «Итог режима»). По нажатию: все подобранные значения переносятся в поля сайдбара,
   галочка подгонки ВЫКЛЮЧАЕТСЯ — тюнер больше не «отыгрывает» правки. Дальше свободная
   ручная корректировка любого параметра.
2. ДЕЛЬТА-СТРОКА в «Сводке» (пока принята цель, а тюнер выключен):
   «🎯 База принята от цели 6:00 → с текущими параметрами получится 6:24 (+6.7%)» —
   живой пересчёт при каждой правке. Кнопка «✖ Сброс» убирает сравнение.
3. Переносимые поля:
   - РАСШИРЕННЫЙ режим (всё): Z-шаг, шаг дорожек, радиальный шаг, скорости F низ/верх,
     энергии низ/верх, верхний лимит тока E0.
   - ПРОСТОЙ режим (существующие поля): Z-шаг, шаг/ширина дорожек, радиальный шаг,
     лимит тока. Скорости и энергии в простом режиме задаются автоматически из базы —
     для их ручной корректировки использовать расширенный режим (честное ограничение).

## Техническая основа и осознанное следствие
Целевые поля переведены на явные ключи session_state (перенос значений кнопкой — штатный
механизм Streamlit). Следствие: эти поля теперь «липкие» — сохраняют введённое значение
и НЕ сбрасываются при смене материала/STL/цели (раньше сбрасывались на рекомендованные).
Для проекта с итерациями по одной детали это скорее плюс; полный сброс — перезагрузка
страницы (F5).
