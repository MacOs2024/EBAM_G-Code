EBAM G-code Studio — запуск на Windows

Если при запуске run_windows.bat написано:
"python" не является внутренней или внешней командой,
значит Python не установлен или не добавлен в PATH.

Решение:
1. Установите Python 3.10 или новее.
2. В самом первом окне установщика обязательно поставить галочку:
   Add python.exe to PATH
3. После установки закрыть все окна cmd/PowerShell.
4. Запустить run_windows.bat снова.

Проверка:
Откройте cmd и выполните:
python --version

Если версия Python появилась, приложение запустится.
